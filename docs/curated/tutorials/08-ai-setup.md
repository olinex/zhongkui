# 第 8 章：如何接入 AI

> 状态：草稿（AI 起草）
> 责任人：@olinex
> 依据：`internal/ai/llmconfig/store.go`、`internal/ai/config/params.go`、`web/src/pages/[language]/admin/llm-config.vue`

本章完成 AI 能力的最小可用配置：一个对话模型、一个向量化模型，并绑定必需档位。完成后顶栏「AI 助手」可用。

## 你将完成什么

- 在「系统管理 → LLM 配置」中登记对话模型与向量化模型。
- 绑定 `standard` 与 `embedding` 档位，使 AI 能力变为可用。
- 打开 AI 助手并收到一次流式回答。

## 前置条件

- 拥有「系统管理 → LLM 配置」的访问权限（通常为管理员）。
- 一个兼容 OpenAI 接口的模型服务地址与 API Key。
- 一个向量化模型及其向量维度；数据库已启用 pgvector 并完成 AI 相关迁移。
- 平台网络能访问模型服务地址。

## 步骤

### 1. 打开 LLM 配置

进入「系统管理 → LLM 配置」。页面有五个分栏：

- 模型：登记可用的对话与向量化模型。
- 档位绑定：把模型绑定到固定槽位。
- Agent 参数：调整工具轮次、检索、会话上下文等行为。
- MCP 服务器：接入外部 MCP 工具。
- 工具：查看与管理 Agent 可用工具。

验证：五个分栏均可切换，模型列表为空时给出空状态。

### 2. 登记对话模型

在「模型」分栏点击新建：

| 字段 | 说明 |
| --- | --- |
| 名称 | 本地展示名，例如 `chat-standard` |
| 模型类型 | 选择对话（chat） |
| API 模式 | `chat`（Chat Completions，默认）或 `responses` |
| 接入地址 | 模型服务 Base URL |
| 凭据 | API Key，加密存储 |
| 模型名 | 供应商侧的模型标识 |
| 超时（秒） | 单次请求超时 |
| 温度 | 0–2 |
| 最大输出 Token | 单次回答上限 |
| 上下文容量 Token | 对话模型必填，Agent 据此计算上下文占用 |
| 启用 | 开启 |
| 描述 | 可选 |

验证：保存后列表显示模型类型为对话、启用状态为开启；凭据列显示为加密值。

### 3. 登记向量化模型

再次新建，模型类型选择向量化（embedding）：

- 填写接入地址、凭据、模型名与超时。
- 填写「向量维度」，必须与数据库向量列维度一致。
- 对话相关字段（温度、上下文容量等）不适用于向量化模型。

验证：保存后类型为向量化，维度列显示你填写的值。

### 4. 绑定档位

切到「档位绑定」分栏，把模型绑定到槽位：

| 档位 | 是否必需 | 用途 |
| --- | --- | --- |
| `standard` | 必需 | 日常问答的默认对话模型 |
| `embedding` | 必需 | 知识库索引与向量检索 |
| `flash` | 可选 | 低时延、低成本对话 |
| `advanced` | 可选 | 复杂推理与长输出 |

只有 `standard` 与 `embedding` 都可用时，AI 能力才算启用。

验证：绑定后列表显示「已绑定」「可用」；缺少任一必需档位时，AI 助手会提示功能未开通并引导到本页。

### 5. 按需调整 Agent 参数、MCP 与工具

- Agent 参数：控制工具调用轮次、检索融合、rerank、会话上下文等；不确定时保持默认。
- MCP 服务器：需要外部工具时按传输方式、地址、请求头与超时接入。
- 工具：查看当前可用工具，确认工具名与描述符合预期。

验证：修改参数后保存成功；MCP 服务器列表显示启用状态；工具列表可见。

### 6. 验证 AI 助手可用

回到任意页面，点击顶栏「AI 助手」：

- 选择命名空间。
- 新建会话。
- 发送一句简单问题，例如「用一句话介绍当前平台」。

验证：回答以流式方式返回；不再出现「功能未开通」提示。

## 成功标志

`standard` 与 `embedding` 档位均绑定且可用，AI 助手能正常发起会话并收到流式回答。

## 常见问题

- **AI 助手仍提示未开通**：检查 `standard` 与 `embedding` 是否都绑定、绑定模型是否启用、模型服务是否可达。
- **向量维度不一致**：更换向量化模型导致维度变化时，先在「档位绑定」解绑 `embedding` 档位，执行 `zki sync embedding-dimensions --dimensions <新维度>` 重建向量列，再执行 `zki sync embeddings --namespace <命名空间>` 重嵌入知识库，最后重新绑定 `embedding`。未解绑时该命令会拒绝执行。
- **调用报鉴权错误**：确认 API Key 未过期，更新模型时留空凭据表示沿用原值。
- **回答很慢或超时**：检查接入地址网络、超时设置与模型服务负载。
