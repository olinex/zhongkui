# 第 11 章：周期性报告讲解

> 状态：草稿（AI 起草）
> 责任人：@olinex
> 依据：`internal/ai/reports/periodic/store.go`、`internal/manager/views/ai/periodicreport.go`、`web/src/pages/[language]/ai/periodic-report.vue`

本章讲清周期性报告的三个对象：技能、计划、运行记录，并手动执行一次报告。

## 你将完成什么

- 理解报告技能、计划与运行记录的分工。
- 创建一个符合周期执行资格的报告技能与计划。
- 立即执行一次计划，并在运行记录中查看报告正文。

## 前置条件

- 已完成[第 8 章](08-ai-setup.md)，AI 助手与 Agent 运行时可用。
- 已读[第 9 章](09-ai-analyze-data.md)，了解技能与知识库。
- 账号下至少有一个「启用且未过期」的访问密钥（「个人资料 → 访问密钥」）。
- 当前命名空间有技能与周期性报告的写权限。

## 步骤

### 1. 认识三个对象

| 对象 | 作用 | 页面 |
| --- | --- | --- |
| 技能 | 定义取数方式、时间窗口与报告结构，正文由 Markdown 指令组成 | AI → 技能 |
| 计划 | 把技能按 cron 排期，提供输入参数、保留天数与失效时间 | AI → 周期性报告 |
| 运行记录 | 每次执行的结果，包含状态、标题、正文与对象存储键 | 周期性报告 → 运行记录 |

报告中心信息流与「关注」用于查看你关心的计划产出。

验证：三个页面都能打开，技能列表区分内置与自定义，计划列表显示下次执行时间。

### 2. 确认技能具备周期执行资格

计划只能选择满足以下条件的技能：

- 来源为自定义，而不是内置技能。
- 已启用，并开启「可周期执行」。
- 固定字段能解析出合法的 `timeOffset` 与 `timeWindow`。
- 输入字段中恰好包含一个 `name=nowTime`、`type=date` 的字段。

验证：在「AI → 技能」中查看目标技能的周期能力、输入字段与固定字段；不满足时，周期计划页的技能下拉不会出现该技能。

### 3. 创建报告技能

进入「AI → 技能」，新建技能：

| 字段 | 说明 |
| --- | --- |
| 名称 | 稳定、可复用的名称 |
| 描述 | 一句话说明报告用途 |
| 正文 | Markdown 指令：取哪些只读能力、时间窗口口径、章节结构与验收标准 |
| 输入字段 | 恰好一个 `nowTime`（类型 `date`）；运行期由平台注入 |
| 固定字段 | 配置 `timeOffset` 与 `timeWindow`，决定统计窗口 |
| 可周期执行 | 开启 |
| 启用 | 开启 |

正文里不要要求运行期向用户提问或等待审批：计划在后台无人值守执行。

验证：保存后技能列表显示启用与可周期执行；输入/固定字段能被计划页识别。

### 4. 创建周期计划

进入「AI → 周期性报告」，点击新建：

| 字段 | 说明 |
| --- | --- |
| 名称 | 计划名称 |
| 技能 | 选择第 3 步的技能 |
| Cron 表达式 | 例如 `0 8 * * *` 表示每天 08:00 |
| 输入参数 | 按技能输入字段填写；时间参数由平台注入 |
| 保留天数 | 1–3650，默认 90 |
| 失效时间 | 留空表示长期有效 |
| 启用 | 开启 |

验证：保存后列表显示技能名、Cron、下次执行时间与启用状态。

### 5. 立即执行一次

在计划行操作中选择「立即执行」。

平台会用计划属主的访问密钥调用只读接口，按固定时间窗口生成一份真实报告。

验证：运行记录中出现一条 `running` 记录，随后变为 `success` 或 `failed`。

### 6. 查看报告正文

打开运行记录详情：

- 状态、触发时间、开始/结束时间。
- 标题、大小、对象存储键。
- 报告正文。
- 失败时的错误信息。

验证：正文包含预期的章节、时间窗口与关键指标；内容与 AI 助手基于同一份数据给出的结论一致。

### 7. 关注与信息流

在报告中心或计划列表中关注该计划。

验证：首页「周期性报告看板」能看到该计划的产出；取消关注后不再出现。

## 成功标志

计划成功执行一次，运行记录为 `success`，报告正文包含预期时间窗口与指标，并能在报告中心查看。

## 常见问题

- **技能下拉为空**：技能不是自定义、未启用、未开启可周期执行，或固定字段/输入字段不满足资格。
- **运行失败提示未授权**：计划属主缺少启用且未过期的访问密钥，或密钥权限不足。
- **报告数据为空**：时间窗口与数据时间范围不重叠，或取数接口的过滤条件过严。
- **正文不符合预期**：技能正文的结构与验收标准不够明确，补充章节、指标口径与空数据说明后重试。
